Picomimi

A sophisticated microkernel operating system for Raspberry Pi Pico. Dual-core scheduling, advanced memory management, and a complete development ecosystem — all in under 64KB.

Powered by AxisOS kernel architecture

Powerful. Efficient. Adorable.

Everything you need to build sophisticated embedded applications on the RP2040.

⚡

O(1) Scheduler

Priority bitmap scheduler with constant-time task selection. Supports 16 priority levels with aging to prevent starvation.

🧠

Dual-Core Support

True SMP with per-core schedulers and work stealing. Automatic load balancing across both Cortex-M0+ cores.

💾

Smart Memory

Coalescing allocator with small-block pools, OOM handling, and pressure monitoring. Every byte optimized.

📁

PMFS Filesystem

Power-safe journaling filesystem for internal flash. Wear leveling, crash recovery, and POSIX-like API.

🔐

IPC & Sync

Mutexes, semaphores, events, and message queues with priority inheritance and deadlock detection.

🎮

HAL Layer

Complete hardware abstraction for GPIO, SPI, I2C, UART, ADC, PWM, DMA, and PIO. Clean C API throughout.

Built from the Ground Up

Picomimi's AxisOS kernel is designed specifically for the RP2040's unique dual-core architecture. Unlike ports of larger RTOSes, every component is optimized for the 264KB RAM and 2MB flash constraints.

The microkernel design keeps the core small and auditable, while services handle everything from logging to GUI rendering. Pure C, pure Pico SDK, pure performance.

Clean, Intuitive API

Write embedded applications with familiar patterns and modern tooling.

main.c 
// Create a simple blinky task with Picomimi
#include "picomimi/kernel.h"

void blinky_task(void* arg) {
    uint8_t pin = (uint8_t)(uintptr_t)arg;
    
    while (1) {
        gpio_toggle(pin);
        task_sleep_ms(500);
    }
}

int main() {
    // Initialize the kernel
    kernel_init();
    
    // Create tasks on different cores
    task_create("blink_0", blinky_task, (void*)25, 5, CORE_0);
    task_create("blink_1", blinky_task, (void*)15, 5, CORE_1);
    
    // Start the scheduler - never returns
    kernel_start();
}

Get Started in Minutes

From zero to blinking LED in three simple steps.

1

Clone the Repository

Grab the latest source from GitHub:

git clone https://github.com/abinaash/picomimi.git
cd picomimi
2

Configure & Build

Set your Pico SDK path and compile:

export PICO_SDK_PATH=/path/to/pico-sdk
mkdir build && cd build
cmake .. && make -j$(nproc)
3

Flash & Run

Hold BOOTSEL, plug in your Pico, and copy the UF2:

cp picomimi.uf2 /media/$USER/RPI-RP2/
