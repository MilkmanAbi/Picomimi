Just another RTOS
A full embedded distribution

Most embedded "operating systems" give you a scheduler and wish you luck. You're left stitching together filesystems, shells, memory managers, and HALs from a dozen incompatible sources.

Picomimi is different. It's a complete, coherent platform where tasks, memory, peripherals, and IPC can be observed and controlled at runtime. Everything works together because everything was built together.

Out of the Box, You Get

Everything you need for complex embedded systems, nothing you don't.

Fully Inspectable

🔌 Hardware Abstraction Layer

Unix-Like, Microcontroller-Sized

Picomimi's architecture resembles a small Unix-like embedded environment: kernel, filesystem, shell, services, and user-space tasks as a unified system.

Clean separation between layers means you can understand, modify, and extend any part without breaking others. Hardware abstraction keeps kernel logic independent of MCU registers.

Get Started

Clone, build, flash — that's it.

1

Clone the Repository

Grab the latest source:

git clone https://github.com/MilkmanAbi/Picomimi.git cd Picomimi
2

Build with CMake

Standard pico-sdk workflow:

mkdir build && cd build cmake .. make
3

Flash & Connect

Copy the UF2, then connect to the shell:

cp picomimi.uf2 /media/$USER/RPI-RP2/ picocom /dev/ttyACM0 -b 115200
